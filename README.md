# Kestrel Labs — model systems ops

Owned by the model systems platform team. Application teams read from this repository; the
platform team edits the policy file.

- `provenance/register.json` — provenance register: which implementation we cite for each
  internal note.
- `screening/queue.json` — candidate repositories produced by the screening search for the
  current note.
- `screening/telemetry.json` — internal adoption telemetry for the candidates in the queue.
- `ports/backlog.json` — sprint port backlog.
- `policy/ports_policy.md` — layout rules for the port tree. Platform-owned.
